# Security Policy

## 1. Supported Versions

Security updates are actively applied to the following versions of MEVIS:

| Version |           Supported           |
| :-----: | :---------------------------: |
|  1.x.x  |        Active Support         |
| < 1.0.0 | Vulnerability Evaluation Only |

---

## 2. Reporting a Vulnerability

We take the security and safety of the MEVIS platform very seriously. Because MEVIS coordinates human operations at mega-events, security risks can directly impact physical event safety.

If you discover a security vulnerability, please **DO NOT** create a public GitHub issue. Instead, report it privately:

1.  Send a detailed description of the vulnerability to the project lead at `security@mevis.event` (placeholder).
2.  Include:
    - The affected component or microservice (e.g., Policy Engine, API Gateway).
    - A step-by-step description of how to reproduce the vulnerability.
    - Any potential impact vectors or proof-of-concept scripts.
3.  We will acknowledge your report within 48 hours and work with you to coordinate a resolution timeline.

Please allow us reasonable time to investigate and address the vulnerability before making details public.
